# v3.1.0-alpha.6 — Ready-to-use Writing and Reliability Fixes

发布于 2026-09-07，标记为预发布（prerelease）。

本版让普通写作任务更直接，同时修正会误拦正常表达或漏掉受保护内容变动的检查问题。
短段落润色、中英翻译、根据笔记起草章节和单条审稿回复，默认先交付可用文本。

## Writing experience

- Simplifies SKILL.md to 115 lines; workspaces, ledgers, and Agent panels remain optional for tasks that need them.
- Reconnects four detailed Chinese/English economics/management guides and relevant adjacent-field guidance.
- Adds eight synthetic worked writing examples, practical method-reporting decisions, and Word/LaTeX delivery guidance.
- Keeps partial evidence gaps local: finish supported portions and identify the missing input.

## Reliability fixes

- Shares recognition of Unicode signs, common quantity units, author-year citations, equations, p-value relations, and LaTeX labels/references.
- Detects negation changes and retains strict protected-field checks in proposal, verification, apply, and workflow paths.
- Fixes method-screen false positives for measurement and negated statements, adds passive-voice parallel-trends checks, and retains affirmative-overclaim failures.
- Separates contextual method advisories from blocking findings; advisories remain visible in reports and workflow history.
- Makes benchmark false positives, false negatives, invalid results, and empty suites fail the gate.
- Aligns route examples, CLI choices, and validation with the route schema.

## Translation

The existing numeric checker accepts an optional flag:

```bash
python scripts/check_numeric_consistency.py original.md translated.md --economic-units --json
```

It compares recognized CNY amounts, percentages, percentage points, and basis points,
and retains the strict numeric result. 元/yuan requires established CNY context.
It does not convert currencies, validate citation translation, prove semantic
equivalence, or relax bounded apply protections. The default remains strict.

## Compatibility notes

- Successful patch proposals now use `risk: checks-passed`.
- An unchanged lexical meaning screen returns `decision: no-known-marker-change`.
- Method reports return `decision: no-known-overclaim` or `review-needed` when there
  are no failing issues, with separate `advisories` and `advisory_count` fields.
  `status: pass` can therefore include contextual advisories; consumers must retain them.
- Old `safe-fix` values remain accepted where the existing report schemas support
  them, but consumers should not require that literal value for new reports.
- Protected snapshots/reports include additional recognized field categories.
  No new runtime dependency or evaluation platform is required.

## Validation and limits

The release candidate passed the unified local suite: 12/12 stages, including
34 writing-contract checks, 12 reliability test groups, 12 Agentic protocol
checks, gold/mutation checks, and synthetic workflow cases. Cross-platform CI
results are linked from the release commit's GitHub Actions checks.

The tests use repository-owned synthetic material. They do not establish real-paper
writing quality, author voice, journal acceptance, live-provider reliability, or
causal identification. No local TeX compiler was available; structural checking
was performed, without claiming successful compilation.
