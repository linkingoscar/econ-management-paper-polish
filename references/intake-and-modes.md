# Intake and intervention depth

Read when the requested actions conflict or a multi-part task needs scoping.
The task routes live in [SKILL.md](../SKILL.md); do not maintain a second router.

## Decide only what affects the work

Infer the requested deliverable, permitted edit depth, research approach,
available evidence, and language from the request and draft. Reuse the user's
preferences. A private one-line note is sufficient; no visible intake form is required.

| Request | Default depth | Information that can genuinely block a part |
|---|---|---|
| Polish / translate / shorten | Preserve meaning and attribution | Ambiguous term or irreconcilable source sentence |
| More scholarly / top-journal style | Improve clarity and argumentative order within supplied evidence | None merely because no journal is named |
| Restructure / rewrite | Reorder, merge, remove repetition; explain substantive changes | Missing context that determines a claim |
| Draft from notes or tables | Write from supplied material | Results needed for a findings claim |
| Review / diagnose | Explain located problems and consequences | Missing artifact needed to judge a suspected error |
| Brainstorm / change topic | Give conditional options based on actual constraints | Data access or scope needed to assess feasibility |
| Literature work | Inspect sources within allowed access | Content not retrieved cannot be treated as read |
| Reviewer response | Separate plans, completed edits, and justified disagreement | Missing revised text prevents verifying completion |
| Exact journal compliance | Verify current requirements for the stage/article type | Unknown outlet or inaccessible official instructions |

"Make it stronger" permits a clearer case, not fabricated findings. "Polish only"
does not authorize changing the conclusion. When an apparent scientific error
survives a faithful edit, give a brief note or clearly separate a suggested
substantive alternative. A request for only revised text should otherwise receive
only revised text.

When partial progress is possible, finish that part. For example, draft motivation
and methods from a study plan while identifying the missing results; do not stop
all writing to request a complete research package.

## Stop when the request is satisfied

Do not add new references, tests, theoretical lenses, alternate versions, or review
rounds merely to show activity. A clear passage can remain unchanged. A limited
contribution can be stated accurately. A feasible narrowing can be preferable to
a costly new study; explain the tradeoff when it matters.
