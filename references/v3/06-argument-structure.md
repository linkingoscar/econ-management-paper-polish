# Argument And Manuscript Structure Pack

## Paper spine

Represent the manuscript as:

```text
central claim → research gap → contribution chain → theory/mechanism
→ hypotheses or predictions → design/estimand → evidence map → implications
```

Every contribution must connect to an observable result or a clearly labelled
conceptual argument. A result paragraph should state the estimate, uncertainty,
economic/practical magnitude, interpretation, and limitation.

## Section routes

- Introduction: problem, gap, question, approach, contribution, roadmap.
- Literature/positioning: organize by unresolved question, not paper-by-paper list.
- Theory/hypotheses: construct definitions → mechanism → boundary condition → testable
  prediction; distinguish theory contribution from empirical novelty.
- Empirical strategy: data, variation, estimand, assumptions, model, inference, threats.
- Results/robustness: baseline first, then diagnostics and alternatives with a reason
  for each check; do not call a checklist a proof.
- Discussion/conclusion: return to the claim, state scope, limitations, and policy or
  management implications without strengthening causality.
