# Writing And Style Pack

## Invariants

For a line polish, preserve numbers, signs, p-values, sample sizes, variable names,
equation notation, table/figure numbers, citation keys, and causal strength. Improve
clarity, order, precision, and discipline-appropriate tone; do not use inflated
adjectives or erase a limitation.

## Four writing routes

| Route | Emphasis |
|---|---|
| Chinese economics | policy fact → research question → identification → economic magnitude |
| English economics | gap → estimand/identification → result magnitude → implication |
| Chinese management | construct → theory mechanism → hypotheses → boundary/implication |
| English management | theory contribution → mechanism → boundary conditions → discussion |

Use the adjacent-field overlay for finance, accounting, marketing, IS, operations,
public management, tourism/service, and innovation. An overlay refines terminology;
it does not replace the primary paradigm route. For bilingual work, keep concepts
and variable labels stable across languages.

## Editing order

1. Repair logical subject and claim-evidence alignment.
2. Remove repetition, vague AI-sounding transitions, and unsupported intensifiers.
3. Make economic or practical meaning explicit after statistical results.
4. Preserve uncertainty: use association language when identification is incomplete.
5. Run `scripts/check_numeric_consistency.py` for meaning-fixed revisions.
