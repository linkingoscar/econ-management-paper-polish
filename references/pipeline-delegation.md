# Optional delegation for complex tasks

Use only when the host permits delegation and a complex task benefits from
independent, separable work. Ordinary polishing, a single source check and a short
method explanation should be done directly. This file does not override host
permissions or the user's scope.

Useful independent tasks can include a bounded literature comparison, a check of
specified tables against prose, or a second review of a central argument.
Choose tasks because their independence improves the work, not to populate roles.

## Handoff

Give each agent:
- The actual user request and bounded task.
- The necessary original material and permitted resources.
- The relevant skill entry or reference.
- The required artifact or concise findings with locators.

Keep outputs isolated when agents generate files. Do not authorize independent
rewriting of the same manuscript sections concurrently.
For an independent evaluation, do not supply the desired verdict or claimed bugs.
Do not claim separate review occurred unless actual independent work was performed.

## Integration

Inspect evidence rather than counting votes. Deduplicate issues, resolve conflicts
against original material and preserve genuine uncertainty. Use one final issue
record and coherent deliverable. The main agent remains responsible for accurate
claims about what was read, changed, checked or run.

If delegation is unavailable or adds little value, perform the relevant work in
one coherent pass. Do not simulate multiple agents or burden the user with several
repetitive role reports. A single-agent workflow is not intrinsically inferior.
